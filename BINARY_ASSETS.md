# Binary asset handling

The seven original Unity asset bundles are **not tracked** in GitHub's source repository because GitHub's browser uploader rejects large files (the ECHO1 bundle alone is over 21 MiB).

The **tested v1.0.1 downloadable release ZIP** on the GitHub Releases page includes all seven bundles. To build this source checkout, obtain the released mod ZIP, and copy the seven files from its `SPT_Runtime/user/mods/FiveF-realisticThermalScopes_lessPixelated/bundles/` tree into `assets/bundles/`, preserving the paths. `assets/bundles.json` provides the required bundle keys. Then run `BUILD_RELEASE.ps1`.

The public repository includes all C# source, manifest, docs, and scripts; it does not contain the Unity binaries. The source archive auto-generated by GitHub is therefore **not** an installable mod package. For players, use the attached release ZIP instead.
